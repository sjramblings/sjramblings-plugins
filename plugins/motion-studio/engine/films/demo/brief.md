# Demo

A 12-second film that proves the harness: four shots, one per engine feature.

| Seconds | Shot | Shows |
|---|---|---|
| 0-3 | `title` | Heavy springs on type, one word per beat, reframed per format |
| 3-6 | `grid` | Staggered `track()` with seeded jitter, a lit diagonal on beat 2 |
| 6-9 | `morph` | One container, never cut: button, card with bars, stamp |
| 9-12 | `lockup` | A counter, then wipes that return to the first frame so it loops |

120 BPM, so a beat is half a second and each shot is one bar and a half.
