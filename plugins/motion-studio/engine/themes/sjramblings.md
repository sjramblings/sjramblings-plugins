# sjramblings: style guide

The default theme. Read by the `clip` skill before it scripts a clip in this theme.

## Scenario

- **Audience:** AWS builders and architects scrolling LinkedIn, YouTube Shorts and sjramblings.io.
- **Remember:** one practical fact, with the limit that comes with it.
- **Feel:** "that's useful, and they told me the catch".
- **Shape:** a series, so the look stays quiet and consistent across many clips.

## Decisions

| Area | Choice | Why |
|---|---|---|
| Colour | Navy ground, one gold accent, red only for the catch | Calm and technical; gold marks the word that matters |
| Stage | A dim blue room with a cool beam | Depth without distraction, so the props stay the subject |
| Type | Signika for hooks and takeaways, Heebo for labels | A friendly display face over a plain, legible UI face |
| End card | Logo, sjramblings.io, "Practical AWS, from the trenches." | The same sign-off on every clip |

## Techniques this series uses

- **Hook:** the problem in the viewer's words, nine words at most. No logo opening.
- **Story:** pain, picture, three moves, the honest catch, one takeaway line.
- **Pacing:** 100 BPM. Something new every two to four seconds. 30 seconds for one fact, 45 for a build scenario.
- **Camera:** the concept stage pushes in on each beat's subject and dims the rest.
- **Voice:** British spelling, no hype, no em dashes, no prices in dollars.
- **Banned:** see the playbook. Also never claim something was built when the clip shows how you would build it.
